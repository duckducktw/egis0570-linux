Linux support for the EgisTec `1c7a:0570` fingerprint sensor (Acer Swift 1/3, 2018-2020).

## Install
Download the packages for your distribution below. The packages replace the distribution's
`libfprint`, so remove nothing first.

- **Ubuntu 26.04**: `sudo apt install ./libfprint-2-2_*egis1*_amd64.deb`
- **Fedora 44**: `sudo dnf install ./libfprint-1.94.100-*egis1*.x86_64.rpm`
- **Arch**: `sudo pacman -U libfprint-egis0570touch-*.pkg.tar.zst`

Then `sudo systemctl restart fprintd` and enroll with `fprintd-enroll` (20 presses).
KDE Plasma users: see "KDE Plasma lock screen" in the README for the clock-view and
suspend/resume fixes (`lockscreen/`).

## What changed vs. the stock driver
- Full-frame touch capture instead of swipe; NCC matcher instead of minutiae/SIFT.
- Threshold 0.49. On 41 presses from 4 unenrolled fingers the best score was 0.468, and none of those presses passes 0.49; about 78% of the owner's single presses pass, and the lock screen retries.
- Adaptive templates are opt-in (`EGIS0570_ADAPT=1`); both field false accepts came through learned samples.
- Five frames per press, strongest first; ~0.1 s match; a finger already resting on the sensor is captured immediately.
- No libfprint "too hot" model: the reader no longer switches itself off after 3 minutes on a locked screen.

## Caveats
- **Not a security boundary.** Numbers come from one user, one laptop (SF314-51); 41 impostor presses cannot establish a false-accept rate. There is no liveness detection. Keep a password, and do not use the fingerprint for `sudo`.
- Not in upstream libfprint yet (draft MR libfprint!662). The next distribution libfprint update overwrites
  these packages; reinstall from the newest release.
- Uninstall: reinstall your distribution's `libfprint` package.

Built and tested by GitHub Actions: each distribution's full libfprint test suite must pass before
packages are attached.
